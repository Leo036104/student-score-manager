# 学生成绩管理系统（C++）

> 大一下学期练手项目 —— 从零手写的第一个完整 C++ 程序。

## 功能

- **添加学生** —— 录入学号、姓名、三门课成绩
- **显示所有学生** —— 以表格形式列出，含总分与平均分
- **按学号查找** —— 输入学号，显示对应学生信息
- 菜单循环、无效选项提示、空数据提示

## 运行方式

1. 用 Visual Studio 2022 打开 `Project1.sln`
2. 按 `Ctrl + F5` 运行

## 项目结构

```
Project1/
├── Project1.sln              # 解决方案文件
└── Project1/
    └── greenhand.cpp         # 全部代码（单文件）
```

## 用到的知识点

- `struct` 结构体、成员函数、`const` 成员函数
- `std::vector` 动态数组（存学生列表、存成绩）
- 函数拆分与引用参数（`vector<Student>&`）
- 范围 for 循环、`std::string` 比较
- 菜单循环（`while` + `switch` 分发）

## 已知问题

- **输入非数字会导致程序死循环**：`cin` 读入失败后进入错误状态，之后所有读取都直接失败。计划用 `cin.clear()` + `cin.ignore()` 修复。
